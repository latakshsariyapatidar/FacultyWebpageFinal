## 🔍 How It Works

1. **Docker Compose** orchestrates 4 services:
   - Frontend (React)
   - Backend (Node.js API)
   - Admin (Node.js Server)
   - Nginx (Reverse Proxy)

2. **All services communicate** via Docker network using container names:
   - `frontend:3000`
   - `backend:8000`
   - `admin:7997`

3. **Nginx acts as entry point** routing to each service:
   - `/` → Frontend
   - `/api/` → Backend
   - `/admin/` → Admin

4. **SSL/TLS termination** happens at Nginx:
   - Certificates loaded from `nginx/ssl/`
   - All traffic encrypted

5. **Data persistence** via volumes:
   - Backend data stored in `backend/data/` directory
   - Survives container restarts

## 🛠️ Troubleshooting

### Problem: Docker not installed
→ Install Docker Desktop from docker.com

### Problem: Services won't start  
→ Run: `docker-compose logs -f` to see errors

### Problem: Port already in use
→ Run: `docker-compose down` then restart

### Problem: SSL certificate error
→ Verify files exist in `nginx/ssl/`
